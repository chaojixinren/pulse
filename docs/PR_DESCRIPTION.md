# 📋 PR: 优化 README 设计，修正项目名称

优化 Pulse 项目的 README.md，修正项目名称并丰富内容，提升项目的吸引力和专业感。

## ✅ 主要变更

### 1. 项目名称修正
- ✅ **修正**: `时笺` → `拾笺`（共 10 处）

### 2. 标语升级
- **Before**: `通过语音记录生活，让 AI 帮你在不同身份间自由切换`

### 3. 内容丰富与润色

- 丰富"我们的理念"章节（原"核心理念"），增加哲学深度

  - 🔐 数据主权，隐私至上 — "隐私不是功能，而是权利"
  - 🌱 科技服务于人 — "技术在后台运行，生活在台前继续"

#### 🎯 功能展示优化
- "核心功能" → "核心能力"
- 新增**表格化信息提取**展示（5 种类型 + 示例）

- 👔 **职场人士** — 会议记录、客户沟通、项目跟进
- 👨‍👩‍👧 **家庭生活** — 亲子时光、夫妻沟通、家庭决策
- 👥 **社交达人** — 朋友聚会、社交网络、活动策划
- 🎯 **自我提升** — 个人反思、习惯养成、时间管理

#### 💫 隐私理念强化

## 🎯 设计理念

本次优化参考了 [BrainDance](https://github.com/tianxingleo/BrainDance) 的 README 设计风格，并融入：

1. **情感化叙事** — 用故事化的语言建立用户共鸣
2. **美学呈现** — 精心设计的视觉层次和排版
3. **价值传递** — 清晰传达"为什么选择拾笺"
4. **场景化展示** — 让用户快速找到自己的使用场景
5. **专业感** — 技术细节与设计美学的完美平衡
