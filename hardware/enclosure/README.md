# 外壳设计 (Enclosure)

Pulse 可穿戴语音采集设备的外壳设计文件。

## 目录结构

```
enclosure/
├── stl/                        # 3D 打印文件
│   ├── Pulse.stl               # 主体外壳
│   └── Pulse_button.stl        # 按钮部件
├── step/                       # CAD 工程文件 (STEP 格式)
│   ├── Pulse.step              # 主体外壳
│   └── Pulse_button.step       # 按钮部件
├── Pulse.f3d                   # 主体外壳 Fusion 360 源文件
└── Pulse_button.f3d            # 按钮部件 Fusion 360 源文件
```

## 设计软件

- **Fusion 360**：主要设计工具，源文件为 `.f3d` 格式
- 如需修改设计，请使用 Fusion 360 打开对应 `.f3d` 文件
- 修改后导出为 STL（3D 打印）或 STEP（协作/加工）

## 组装说明

1. 将按钮部件安装到对应位置
2. 将 PCB 放入主体外壳对应的卡槽
3. 盖上屏幕，确认所有接口（USB、麦克风孔）露出
4. 必要时使用胶水或螺丝固定

## 注意事项

- 外壳尺寸需与 PCB 实际尺寸匹配，如有差异请调整 Fusion 360 源文件
- 麦克风开孔需保证收音效果，避免被外壳遮挡
- 按钮行程空间需预留充足，避免卡死
- 充电接口（USB-C）开口需对准设备接口位置
